# Руководство по Kimi WebBridge

## Что это

Kimi WebBridge позволяет AI управлять браузером — заходить на сайты, кликать, заполнять формы, скроллить.

## Зачем тебе

Автоматизировать поиск туров на сайтах туроператоров (Корал Тревел, TUI и др.), где нет API.

## Базовые команды

### Навигация
```
Перейди на https://coralagency.ru
```

### Поиск
```
Найди тур: вылет Москва, даты 30.09, 9 ночей, 2 взрослых + 2 детей
```

### Скроллинг
```
Прокрути страницу вниз
```

### Клики
```
Кликни по кнопке "Найти туры"
```

## Рабочий процесс для подбора

1. Залогинься на сайт туроператора
2. Заполни форму поиска
3. Собери результаты (название отеля, цена, даты)
4. Сохрани в JSON
5. Проанализируй и отфильтруй
6. Создай презентацию

## Важно

- Сайты туроператоров часто меняют структуру
- WebBridge работает через Chrome DevTools Protocol
- Для защищённых страниц нужна авторизация (cookies)
- Не злоупотребляй — сайты могут блокировать частые запросы

## Советы

- Делай скриншоты для проверки
- Используй `wait_for` перед кликами
- Проверяй, загрузилась ли страница
- Сохраняй сессию (cookies) между запросами
